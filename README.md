# FUTO Music
FUTO Music is a music player specializing in on-device music. Playing your music you own without relying solely on a streaming service.

Little to no AI/Agentic generated code was used in the making of this codebase.

## Currently in Alpha
We are actively working on this app, and lots may improve and change in short amounts of time. 

Updates are provided through the in-app updater (through in-app notifications).

Metadata tagging is planned for a release very soon.

We try to avoid any incompatibility between updates, but it is not impossible to happen in these early versions.

## Goals
 - A polished music player
 - Personalized on-device smart shuffle (WIP)
 - Music metadata tagging (Planned Soon)
 - Source First licensing

## How to obtain Music (DRM-Free)
There are several ways to obtain music files legally.

- [Bandcamp](https://bandcamp.com)
- [Qobuz](https://www.qobuz.com)
- [7digital](https://www.7digital.com)
- [HDtracks](https://www.hdtracks.com)
- [Apple / iTunes Store](https://www.apple.com/itunes/) (purchases only — Apple Music streaming is DRM-protected; 256kbps AAC, no lossless)
- [Amazon Music](https://www.amazon.com/music) (purchases only — streaming is DRM-protected; MP3-only, no lossless)
- [Boomkat](https://boomkat.com) (electronic/experimental; MP3/FLAC/WAV)
- [Bleep](https://bleep.com)
- [Beatport](https://www.beatport.com)
- [eMusic](https://www.emusic.com)
- [NativeDSD](https://www.nativedsd.com)
